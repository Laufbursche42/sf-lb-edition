Ride log
Record ride log
Off by default. Records the telemetry snapshot the scooter sends, once per minute while you ride: speed, ride mode, battery level, pack voltage and current, power, trip and total distance and the fault code. Recording starts as soon as the scooter first moves. All rides are kept until you delete them.
View the exported CSV/JSON as graphs with the Laufbursche Edition Analysis Tool (leat).
